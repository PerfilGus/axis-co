# Axis

Sistema de gestão para venda com pagamento na entrega (PAD).

```bash
npm install
npm run dev
```

Abra http://localhost:3000. O seletor de perfil no cabeçalho (visível apenas em
desenvolvimento) troca entre Admin, Vendedor e Financeiro para testar as
permissões.

| Comando | O que faz |
| --- | --- |
| `npm run dev` | Sobe o servidor de desenvolvimento |
| `npm run build` | Build de produção |
| `npm run lint` | ESLint |
| `npm run typecheck` | `tsc --noEmit` |

Veja `CLAUDE.md` para o mapa do código e as convenções.
